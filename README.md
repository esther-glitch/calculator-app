# Calculator App 🧮

A simple Python calculator app built using Tkinter. It performs basic arithmetic operations like addition, subtraction, multiplication, and division.

## Features
- GUI interface using Tkinter
- Basic operations (+, -, ×, ÷)
- Clean and user-friendly design

## How to Run
1. Install Python (if not already installed)
2. Run the script:
```bash
python calculator.py
